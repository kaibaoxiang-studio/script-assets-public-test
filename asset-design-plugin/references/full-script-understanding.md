# 全文理解与跨资产设计意图

## 阅读必须发生

自动切分只生成来源单元，不生成理解。先检查台账中的来源哈希及单元目录，阅读全文并逐段记录覆盖；长剧本按集、场或连续文本块读完，再联读关键前后文。未读、缺页和无法解析分别说明，不能把资产表、全文检索命中或抽样阅读写成完整覆盖。复用上下文须确认来源版本与覆盖一致；来源变化后补读变化单元和受影响前后文，旧版综合理解只作比较。

综合应回答故事由什么冲突驱动、什么选择造成转折、角色与环境／物件怎样相互作用、哪些信息在何时对观众可见。区分实际行动、人物自述、他人评价、叙述事实与传闻。相互矛盾的言行可能是伪装、误读或人物变化，引用多场证据，不用一个标签压平。

母插件建立全剧公共理解，不替子插件完成所有垂类分析。轻量覆盖清单中的每类资产及重要关系，当前批次再深化。角色的欲望与身份反差、空间的布局逻辑、道具的具体构造分别交其领域。

## 将理解变成美术工作

从世界可达技术、生产工艺、气候与空间、资源取得和维护方式，提取实际约束；从叙事作用、关系权力、身份公开程度和人物弧线，提取观众应先读到什么、应延迟知道什么。规则必须能落实到形状、结构、材质、颜色、尺度、穿戴／放置或使用关系。例：“长期潮湿、依赖维修”可以要求可拆维护、连接保护和局部磨损提案，不能唯一推出固定族群面孔、贫穷者脏乱或所有材料锈蚀。

每条关键设计依据保留来源定位，并标明：明确事实、用户批准、合理推导、创作选择、未知。没有唯一因果的脸型、比例和装饰仍可主动推荐，不能编造经历证明；新增家族、宗教、组织或剧情功能须单列确认。知识提供方法，不提供本剧事实。隐藏身份可参与内部推理，不能因此在初始衣装、道具或空间刻上提前泄密的符号。

项目美术基准写共同世界逻辑及各领域如何适配，例如同一工艺如何在衣扣、家具连接和器具表面各有表达。保留同世界中的地域、阶层、职业和个人差异，不把统一理解简化成全员同色、同纹样。

## 资产关系与设计依赖

关系至少定位双方资产／状态、出现时刻、证据及约束：谁持有／穿戴／操作、何物位于何处、谁需要通过或坐卧、何物会改变空间状态。别名和同名物件不自动合并，不确定的对应关系显式待核。表外物件只列候补，不静默写入正式表。

把“存在关系”与“必须等上游”分开。只有设计结果确实依赖某项已定结构、尺度或批准时才设硬依赖；可同时约定范围的任务先共享约束后并行。例如手持器具可先协定握持范围与携带方式，再分别深化手部姿态和把柄，不必无休止互等。循环冲突应提交最小共同决定，并说明影响项。

## 对用户的呈现

用户看简洁的全剧判断、当前设计意图、关键关系和推荐取舍；来源覆盖、证据与任务细节保存在项目文件。不要要求用户逐项阅读后台分析表。文字自检可检查来源、机制和相容性；只有真实图片才可报告剪影、遮挡或同框识别通过。
