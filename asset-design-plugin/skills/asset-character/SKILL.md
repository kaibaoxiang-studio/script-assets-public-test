# 角色资产入口

完整读取包内 [角色资产主控](../../bundled-plugins/character-assets/skills/character-assets/SKILL.md)，在该子插件根目录解析它的全部相对引用并执行本次角色任务；它的知识、阶段合同、比例、模卡、群演分类、画幅、命名与图片审批规则继续适用。不得因母插件存在而跳过人物分析或服饰设计，或将其他领域的产物视为角色已批准基准。

收到母插件的任务时先读 [交接](../../references/domain-handoff.md)，核对原剧本、人物与状态 ID、语境、阶段、基准和约束。共同全剧上下文可帮助定位；只有满足角色子插件上下文合同且来源一致时才能作为其全文理解复用，否则按其方法补读，不能把摘要声明为全文。没有正式角色项目仍可独立文字设计，临时标识不写成标准 ID。

需要独立子任务时使用包内 harness 的隔离执行，不创建可见派发聊天。直接使用本入口时不启动跨域总控，不强制建立母项目；保留原子插件的具体设计、提示词及当前阶段交付。需要登记到母项目时，通过任务返回物或有原批准记录的 `register-delivery` 登记，批准权和版本规则见 [审批](../../references/approval-and-change.md)。
