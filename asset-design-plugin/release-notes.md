# 资产设计插件 v0.1.0

> 本文保留 2026-10-23 原私有正式版发布说明。当前副本是其公开测试镜像，版本保持不变；公开化变换、来源散列和镜像本地回归另见 `public-export-manifest.json`。下述真实调用与原仓库安装结果属于上游历史验证，不表示镜像重新执行。

从完整剧本建立共同美术基准，按资产依赖统筹角色、场景和道具设计。母插件负责跨域理解与整合，三个子插件保留专业设计方法和原审批边界。

- 四个直接入口：`$asset-design`、`$asset-character`、`$asset-scene`、`$asset-prop`。
- 单包内置角色 v0.2.6.2、场景 v1.0.0、道具 v0.2.0；来源提交、432 个文件的哈希和权限均有锁版记录。
- 全文阅读覆盖、版本化美术基准、依赖调度、临时执行会话、结果与知识收据、局部失效和统一资产索引。
- 显式导入旧角色项目，核对来源、ID、设计记录、提示词、图片与审查的对应关系，保留原批准记录。
- README 内直接展开工作流、时序图和数据流图。

32 项回归通过；三领域完成真实文字调用，原始设计稿和可复核记录见仓库 `validation/`。本轮不以生成新图作为发布门槛，完整项目和图像审美由使用者测试正式版。

下载 ZIP 后解压，在目录内用 Python 3.12+ 运行 `python3 scripts/install.py`，再新开聊天使用四个入口。安装包包含全部锁版子插件，不依赖已安装的其他业务插件。

本正式版发布于开宝箱独立私有仓库 `asset-design-plugin`；ZiChan 的原提交和工作区均未变更。
