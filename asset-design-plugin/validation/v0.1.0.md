- 32 项确定性测试通过，覆盖来源覆盖与版本、正式／临时 ID、依赖与循环、独立失败、批准归属、局部失效、外部文件改动、旧角色项目导入、启动竞态及中断取消。原记录见 [unit-tests.txt](unit-tests.txt)。本地 RPC 夹具只验证传输机制，不证明设计能力。
- 包内角色 v0.2.6.2、场景 v1.0.0、道具 v0.2.0 的 432 个来源文件与锁版提交逐字节一致；四个公开入口通过检查。见 [结构校验](package-validation.json) 和 [运行环境](doctor.json)。
- Creator 检查实际插件的 Skill 引用、元数据、JSON Schema 和 Python 语法均通过；能力层蓝图也经 Creator build 成功组装。该构建证明不冒充正式自定义运行时的验证，运行时另由测试和实际调用验证。构建蓝图 SHA256：`2f64c6e47accb37c06da9cd32dd92b1b154e3930e22ec267fe4c75432eace13e`。
- 同一份两场合成剧本，三个子插件通过真实 App Server 临时会话调用完成，未指定模型覆盖。角色调用 character-design，其余调用各领域主入口；调用耗时分别为角色 434 秒、场景 516 秒、道具 415 秒，三项并行。耗时为本机单次样本，不代表生产性能。
- 已核对角色稿的跨场人物反差及具体面部、发型、肤质；场景稿的单一时刻、狭长低台、工作与通行关系；道具稿的铜制和擦槽约束、三案结构及待选状态。真实文件、结果、知识路径与哈希见 [调用记录](real-call-report.json) 和 [原始输出](real-calls/)。
