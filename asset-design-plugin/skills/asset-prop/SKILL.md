# 道具资产入口

完整读取包内 [道具概念设计](../../bundled-plugins/prop-assets/skills/prop-concept-design/SKILL.md)，在其根目录解析相对知识与专项入口。遵循其批量／逐件模式、出场频率核对、概念选案、Prompt 表和主视觉回流规则，不用母插件推荐代替用户选案，也不因批量任务自动批准设计或图。

接收母任务时按 [交接](../../references/domain-handoff.md) 核对原 ID、基础资产与状态、剧情用途、操作者和空间关系、尺度依据、当前阶段及已确认保持项。全剧理解提供用途与叙事目标，轮廓、结构、材质、配色和纹样由道具子插件具体设计；建议尺寸、推测结构与真正有来源的数值分别标注。角色手持或场景摆放关系尚无定案时，提出相容的设计范围，不虚构精确测量。

直接调用只做道具领域，不强制启动总控或建立母项目。需要独立任务时用包内临时执行器，不创建可见派发聊天。保留原 Prompt 表、选案记录、图片审核及派生项版本；母项目登记只说明采用和交付情况。图片未回流不得登记主视觉通过，详见 [审批](../../references/approval-and-change.md)。
