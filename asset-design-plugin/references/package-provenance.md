# 封装来源与独立更新

母插件版本为 v0.1.0，安装与正式发布仓库为 `kaibaoxiang-studio/asset-design-plugin`。三个子插件来自 ZiChan 的锁版快照：角色 v0.2.6.2、场景 v1.0.0、道具 v0.2.0。实际来源提交、每个文件和整体摘要以根目录 `bundle-lock.json` 为准。

快照保留原插件根目录、知识、脚本和来源说明，入口包装不复制改写其专业规则。母包运行不依赖本机另装同名插件或 Harness Creator；现有独立插件可并存。四个新入口使用独立名称，用户可直接调用某一领域。

子插件源仓库继续独立维护。更新快照时必须显式选择来源提交与版本、重新生成锁定记录、检查接口和原相对引用，并完成受影响领域的真实调用；不能跟随远端最新分支静默更新。母项目记录实际执行版本，旧产物保留其原版本依据。

本次母插件建设不修改 ZiChan，源仓库只是只读导入来源。发布前核对源提交与工作区状态，安装包检查封装文件是否与锁版记录一致。保留子插件来源和随附许可证；母插件新增方法和适配代码不替代其来源声明。
