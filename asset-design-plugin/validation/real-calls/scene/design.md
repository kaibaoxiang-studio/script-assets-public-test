# SCN-001｜潮门修理铺｜S01 黄昏

## 第一阶段文字设计

**依据与时刻**：资产表确认海堤旁的狭长修理铺和低矮工作台；剧本 1-1 是黄昏、暴雨将至，铜闸钥匙握在林禾手中。1-2 仅用于核对铺内通往门外的固定关系；夜场的旧帆布、防水披肩及雨夜状态不进入本画面。S01 是本任务的黄昏画面标识，不新增正式场景状态或资产条目。

**本轮美术提案**：让低工作台沿一侧长墙形成连续的工作边，台前保留狭窄但不断开的单条通道；靠入口的台面短端留平整、干燥的临时放置面，以台腿、桌沿和入口门框共同定位工作、放钥匙与离开的关系。工具集中在台的内侧工作段，浅收纳贴墙，避免把操作面或通道堆满。灰棕墙面、深棕木台和暗灰金属保持材料本色；海边盐雾与水痕只落在暴露处。黄昏冷灰天光与台上有限的暖色工作光分层。配色仅参考库条目 010 的冷灰蓝绿、哑灰棕与木色相邻关系，并按本场材料和光源重新分配，不沿用其人物、情绪或比例设定。

## 完整中文静态提示词

```text
写实影视美术质感的无人静态场景，黄昏、暴雨将至的海堤旁「潮门修理铺」。小铺室内沿入口到内墙的方向明显狭长，两侧长墙相距很近，不把空间扩成宽敞工坊；入口在远端短墙，门框旁一扇普通窄窗只露出海堤轮廓、压低的云和有限的灰蓝天色。从铺内向入口看，左侧长墙贴着一张低矮的长工作台，台板顺房间长轴展开，矮厚木腿与横向拉撑清楚承托台面；台前到对侧墙之间是一条连续、仍显局促的通道，一直通向入口，门前不被柜架或工具截断。

工作台靠内端的后沿固定一处朴素手动夹具，墙面短挂条收着少量钳、锉等常用手工具，台下沿墙侧是浅格收纳；这些使用物集中在工作段，台面前沿仍能操作。台的入口侧短端留一块清楚可见的平整空木面，和夹具工作段分开，供手持的钥匙临时放置；此刻台面没有钥匙。台前靠内端、介于可见台腿与内侧墙角之间留出操作停留面，面向台板；从该处沿台前通道可到入口侧的空台面，再接到门前地面，路线保留原有狭窄感。台面、台腿、门框是可辨的固定参照，没有站位标记或箭头。

墙体为哑光灰棕抹灰，靠外侧开口与墙脚有少量盐雾泛白；深棕木台的板缝顺长轴延伸，常触的前缘磨润，腿与拉撑的连接朴素可见，暗灰金属夹具和挂条只在接触边缘有局部磨亮。石质地面偏灰褐，入口附近的暴露处有有限潮痕，铺内工作台下保持较干的钝面，不做全屋湿亮或统一刷旧。窄窗与入口方向的阴云天光以低饱和冷灰蓝照到通道和台面前缘；固定在工作台内侧上方的一盏带遮罩普通工作灯，以有限暖白光照亮夹具旁的操作面，并略及入口侧的空台面，光向内墙与通道远侧自然衰减。材料固有的灰棕、深棕和暗灰仍可分辨，不用整幅蓝色滤镜。

相机位于铺内侧短墙附近、略偏通道右侧，以接近胸口的视高沿狭长轴线朝入口观察，轻微俯视，让低台的台面、支腿、入口侧空台面、台前窄通道和远端门框同时可见；采用克制的自然透视，不以超广角拉宽房间。画面没有人物、铜闸钥匙、旧帆布或防水披肩，也没有新增标志、特殊装置、动作过程与夜景事件痕迹。
```
