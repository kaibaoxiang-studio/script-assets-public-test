# 场景资产入口

完整读取包内 [场景图提示词](../../bundled-plugins/scene-assets/skills/sence-prompts/SKILL.md)，保留其根目录并按原相对引用读取本轮模式的参考。新建、打光、反打、局部修改和纹理修复按场景子插件路由；不将角色或道具的展示模板、画幅、图片链路套给场景。

接收母任务时按 [交接](../../references/domain-handoff.md) 核对来源、原 ID、子场景粒度、单一剧情时刻、当前图／文字基准及授权范围。母基准提供适用的时代、材料、光色和跨域交互约束；具体布局、人物是否入画、陈设与关键道具如何呈现，以场景子插件准则和本次用户范围为主，不另加一条跨项目通用禁令。图与设定冲突保留证据，不能凭版本较新自动选边。

直接调用时只推进本次场景任务，不强制母项目或重做全表。需要独立子任务时使用包内临时执行器，不能创建可见派发聊天。交付保留原场景提示词、色卡和适用基准；母项目只记录实际返回物与采用状态，不把文字核对称为空间实测或图片通过。审批和失效见 [审批](../../references/approval-and-change.md)。
